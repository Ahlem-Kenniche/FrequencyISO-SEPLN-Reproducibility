# SPARQL functional queries (GraphDB)

The `.rq` files are preserved from the queries previously executed by the author in GraphDB 11.5.1 (local research repository). Run them against a GraphDB RDF import using the Prolexbase ontology URI shown in each query.

Q0: 270,314 annual observation resources; Q1: five records (Arabic prolexeme 19537); Q2: 15 records (pivot 64621 in AR/EN/FR); Q3: 1,466 entries changing class between 2022–2023, with language-level direction counts in the accompanying CSV.

**Scope:** these are recorded user-executed GraphDB results. The distributed SQL is not a full runnable RDF/GraphDB snapshot. Q3 checks for transitions, but SPARQL results are not a proof of exhaustive SQL–RDF equality. The tests do not assess downstream retrieval performance.
