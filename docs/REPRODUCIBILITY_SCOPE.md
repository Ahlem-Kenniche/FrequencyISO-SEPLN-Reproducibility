# Reproducibility scope — peer-review package

**Verified:** stored ordinal class distributions (Table 1), 2019–2023 matched transitions (Table 2), the unique 2,812-pivot trilingual cohort, 26,318/26,318 matches to archived FR+EN labels (retained 2022/2023 cohorts), frozen-weight counterfactuals, five-indicator ablation in FR/EN/AR retained cohorts, leave-one-entry-out effects in FR/EN/AR, and arithmetic of the 6/9 GDELT pilot.

**Partial:** perturbation. The provided seed-42, 200-replicate simulation is an independent reimplementation with 0.5818% FR and 1.0175% EN mean changed labels. The original randomization scheme is not established; the manuscript's 0.58% / 1.02% values are rounded from this independently specified test; they do not establish equivalence to any earlier randomization protocol.

**Not claimed:** exhaustive historical five-indicator Wikipedia extraction for all languages and years, independent evidence of genuine popularity changes, externally validated gains in entity linking, or GDELT annual event counts. Arabic workbook is an undated retained cohort.

**Data reuse:** The SQL contains a modified Prolexbase 4.1 resource without derivative and instance tables. Full license/rights verification for every included contribution remains necessary before public distribution.
